Roles & Permissions Management

Roles & Permissions Management

Control who can access what features by setting up roles and assigning permissions.

Default Roles

Role Description Permissions
Company Admin Full system access All features, settings, user management, reports
Department Manager Department-level control View department employees, attendance, reports; manage leaves
Team Lead Team supervision View team members, attendance, basic reports
HR Manager Human resources access Employee management, leaves, payroll data, compliance reports
Employee Standard employee access Check in/out, view own attendance, see messages
Viewer Read-only access View reports and data only, no editing capabilities

Assigning Roles

1

Go to User Management

Navigate to "Users" or "Team" from the menu

2

Select Employee

Find and click on the employee whose role you want to modify

3

Change Role

Click "Edit" and select the new role from the dropdown

4

Set Department (if applicable)

If assigning a manager role, select which department they'll manage

4

Save Changes

Click "Save" and the employee's access will update immediately

Security Note: Always follow the principle of least privilege—give users only the access they need for their role.
