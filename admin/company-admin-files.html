Files

Manage and organize your company's files — upload, share, approve, and track document status across teams.

Managing Company Files

The Files page is your centralized document management hub. Store, organize, and track important files with approval workflows, department assignments, and location-based access controls.

File Status Overview

Total Files

Complete count of all files in your system.

Approved Files

Files that have been reviewed and approved.

Pending Files

Files awaiting review or approval.

Deleted Files

Files moved to trash but recoverable.

Filtering and Searching

1

Search by File Name

Type in the search box to find files by name or keywords.

2

Filter by Status

Show files by approval status: All, Approved, Pending, Rejected.

3

Filter by Type

Filter by file type: PDFs, Images, Documents, Spreadsheets, etc.

4

Filter by Department & Location

Narrow results by department or work location.

Files Table Columns

Column What it shows
File Name Name and type of the uploaded file
Description Notes or context about the file
From Which department/person uploaded it
To Target department or recipient
Type File format (PDF, Word, Image, etc.)
Created At When the file was uploaded
Actions Download, approve, reject, or delete options

Quick Actions

  • + Create New File — upload a new file to the system
  • View Trashed — recover deleted files
Tip: Use clear file names and descriptions so team members can easily find what they need. Organize files by department or project for better file management.
