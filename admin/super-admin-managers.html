SUPER ADMIN GUIDE

Managers

View every Company Manager on the platform, check their verification status, and see which companies each one is assigned to.

Managing Company Managers

The Managers page gives Super Admins a platform-wide list of Company Manager accounts, along with quick filters and per-manager actions.

Filtering the Manager List

1

Search

Type into the Search box to find a manager by name or email.

2

Filter by Status

Use the Status dropdown to show only Active or Inactive managers.

3

Apply or Clear

Click Filter to apply your search and status filter, or Clear Filters to reset the list.

Reading the Managers Table

Column What it shows
Profile Photo The manager's photo or avatar
Full Name Manager's name and internal ID
Email Registered email address
Department Role badge — typically Company Manager
Salary Type Salary type if applicable (shows "-" if not set for a manager account)
Status Active or Inactive badge
Verified Whether the manager's account has been verified
Assigned Companies The company (or companies) this manager oversees. If assigned to more than a few, a "+N more" link expands the full list.
Actions Open the Actions menu to view, edit, deactivate, or reassign the manager

Other Actions on This Page

Managers Create

Click Managers create in the top-right to open a form for adding a new Company Manager, similar to the employee creation form — enter their personal details, assign a company, and set their login credentials.

Trashed Employees

Click Trashed Employees to jump to the trashed records list if you need to restore a removed manager or employee.

Tip: If a manager is assigned to multiple companies, click "+N more" under Assigned Companies to confirm exactly which companies they can access before making any changes to their role.
