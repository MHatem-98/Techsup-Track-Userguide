Trashed Projects

View deleted projects that can be recovered — restore archived projects or permanently remove them from the system.

Managing Trashed Projects

The Trashed Projects page shows all projects that have been deleted or archived. From here, you can restore projects you accidentally deleted or permanently remove them if they're no longer needed.

Understanding Trashed Projects

When a project is deleted from the main projects list, it moves to the trash rather than being immediately removed. This gives you a grace period to recover it if needed. Projects stay in trash for a set period before being automatically purged.

Trashed Projects Table

Column What it shows
Project Name The name of the deleted project
Company Which company owned the project
Owner Who created or managed the project
Status Status it had before deletion
Priority Priority level (High, Medium, Low)
Progress Completion percentage at time of deletion
Deleted At When the project was deleted (timestamp)
Actions Restore or permanently delete options

Restoring a Project

1

Find the Project

Locate the project you want to restore in the trashed list.

2

Click Restore

Select the Restore action to move the project back to the active projects list.

3

Verify

The project is now restored and appears in your All Projects list with all original data intact.

Permanently Deleting a Project

To permanently remove a project from the system:

  1. ⚠️Delete Permanently action on the project row.
  2. ⚠️Confirm the action — this cannot be undone.
  3. ⚠️The project and all associated data are immediately removed.
Warning: Permanent deletion is irreversible. Make sure you no longer need the project before permanently removing it. Consider exporting project data first if you need a record.
