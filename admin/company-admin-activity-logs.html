Activity Logs

Track all system activities and user actions — view who did what, when, and which data was affected across your entire company.

Understanding Activity Logs

The Activity Logs page provides a chronological record of every action taken in the system — employee creations, profile updates, file uploads, login attempts, and more. This is critical for compliance, auditing, and troubleshooting.

What Gets Logged?

  • Employee Actions — creates, updates, deletions, and status changes
  • Login & Access — who logged in, when, and from where
  • Data Changes — updates to company information, settings, or policies
  • File Operations — uploads, downloads, sharing, and deletions
  • Administrative Actions — permission changes, role assignments, system settings

Filtering Activity Logs

1

Filter by Action

Select an action type to narrow results — view only creates, updates, deletes, or logins.

2

Filter by Model/Entity Type

Choose what was affected — Employee, File, Project, Shift, etc.

3

Filter by Date Range

Specify From and To dates to see activities within a specific timeframe.

Reading the Activity Log Table

Each row in the Activity Log shows:

Column What it shows
User Who performed the action
Action What was done (Created, Updated, Deleted, etc.)
Model What type of data was affected (Employee, File, etc.)
Details Specific record affected (e.g., employee name or file name)
IP Address Where the action was performed from
Date When the action occurred (timestamp)
Tip: Use Activity Logs for compliance audits, security investigations, or to track who made changes to sensitive data. Export logs periodically for archival.
