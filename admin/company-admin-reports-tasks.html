Reports by Tasks

Monitor project task progress — completion rates, task assignments, and status snapshots across your company's active projects.

Understanding Tasks Reports

The Reports by Tasks page shows you a detailed view of all tasks across your company's projects — which are open, which are completed, who's assigned to what, and overall project progress.

Key Metrics Tracked

  • Total Tasks — count of all tasks across active projects
  • Active Tasks — tasks currently in progress or not yet started
  • Completed Tasks — tasks marked as done
  • Overdue Tasks — tasks past their due date without completion

How to Use This Report

1

Monitor Progress

See at a glance which projects are on track and which need attention — high numbers of overdue tasks signal potential bottlenecks.

2

Identify Workload Imbalances

Check if certain team members or projects have disproportionate task loads and rebalance assignments if needed.

3

Forecast Project Completion

Use completion rate trends to estimate when current projects will be finished and plan resource allocation accordingly.

4

Generate Reports for Stakeholders

Export this report to share project status updates with executives or clients in a clear, data-driven format.

Tip: Review this report weekly during team meetings to celebrate completed tasks and collaboratively address any blockers on overdue items.
