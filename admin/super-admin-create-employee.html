SUPER ADMIN GUIDE

Create New Employee

Add a new employee to a company directly from the Super Admin panel — personal details, employment terms, contract dates, and account security in one form.

Creating a New Employee

From the sidebar, go to Employees → Create New Employee. Make sure you have the correct company selected under Select Company first, since the employee will be created under that company.

Section 1 — Personal Information

1

Profile Photo

Click Choose File to upload a profile photo.

The profile photo must not exceed 2MB.
2

Name & ID Number

Enter the employee's First Name*, Last Name*, and ID Number* — all three are required.

3

Email & Contact Number

Enter the employee's email address and contact/phone number.

4

Address

Enter the employee's residential address.

Section 2 — Employment Information

1

Salary Type & Salary

Choose the Salary Type from the dropdown (e.g. Salaried), then enter the Salary amount in SAR.

2

Hourly Rate

If the employee is paid hourly rather than salaried, enter their Hourly Rate.

3

Education Level

Select the employee's highest education level from the dropdown.

Section 3 — Contract Information

Set the Start Contract and End Contract dates. Leave the end date blank for an open-ended contract.

Section 4 — Security Information

Set the employee's initial login credentials by entering a Password* and repeating it in Confirm Password*. Both fields are required and must match.

Section 5 — Settings

  • MOL TWC Compliance — toggle on if this employee's records need to comply with Ministry of Labor / TWC reporting requirements
  • Status — set the employee's initial account status from the dropdown
  • Auto Fill Attendance — toggle on to automatically fill attendance for this employee
  • Can Edit Own Shifts — toggle on to allow this employee to adjust their own shift schedule

Save the Employee

Once all required fields are complete, click Save to create the employee, or Cancel to discard the form.

Tip: New employees created this way typically appear as Pending and Unverified in the Employees List until they're reviewed — check the Verify Employees page to confirm and activate them.
