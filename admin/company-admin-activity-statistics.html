Activity Statistics

Visualize system activity trends — see which users are most active, when peak activity occurs, and what types of actions dominate.

Understanding Activity Statistics

Activity Statistics transforms raw activity log data into visual dashboards and charts. This page helps you spot patterns, identify power users, understand system usage trends, and monitor engagement across your company.

Key Statistics Displayed

Most Active Users

Ranking of users by number of actions — shows who's most engaged with the system.

Activities by Action Type

Breakdown showing which actions are performed most frequently — creates, updates, deletions, etc.

Activities by Model Type

What entities receive the most changes — Employee data, Projects, Files, etc.

Activities by Date

Trend line showing activity volume over time — spot busy periods and anomalies.

Using Filters

Customize the statistics to match your analysis needs:

  • Filter by Action Type — focus on specific action categories
  • Filter by Model Type — see data for specific entities
  • Set Date Range — analyze activity within a specific time period

Use Cases

1

Monitor System Health

Track activity trends to ensure the system is being used as expected and identify anomalies.

2

Identify Power Users

See which team members are most active — useful for recognizing adoption and training success.

3

Plan Capacity

Understand peak usage times to plan maintenance windows and resource allocation.

Tip: Review Activity Statistics monthly to understand adoption trends and identify users who may need additional training or support.
