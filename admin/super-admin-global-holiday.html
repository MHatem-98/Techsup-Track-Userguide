Add Global Holiday

Create a holiday that applies across all companies on the platform.

Creating a Global Holiday

Global holidays are platform-wide closures that affect attendance and shift calculations for every company. Use this page to add holidays like national days, company-wide observances, or system maintenance windows.

Holiday Information

1

Holiday Name*

Enter the name of the holiday (e.g. "Eid Al-Fitr", "National Day", "Company Closure"). This field is required.

2

Start Date* & Start Time*

Enter when the holiday begins. The date format is mm/dd/yyyy and the default time is 12:00 AM. Both are required.

3

End Date* & End Time*

Enter when the holiday ends. The default end time is 11:59 PM. Both are required.

4

Reason

Optionally, enter a reason or description for the holiday (e.g. "National holiday" or "System maintenance"). This field is optional.

Attachments

You may optionally upload supporting documents (images, PDFs, etc.) related to the holiday — for example, an official public holiday announcement.

  • Click Choose Files to browse and select one or more documents
  • File types supported: images (PNG, JPG), PDF, and other common document formats
  • Leave this section blank if no attachments are needed

Save the Holiday

1

Review Your Entries

Double-check the holiday name, dates, times, and reason before saving.

2

Click Create Global Holiday

Once all required fields are complete, click Create Global Holiday to save it to the platform.

3

Or Cancel

Click Cancel (or use Back to Holidays in the top-right) to abandon the form and return to the Holidays list without saving.

Tip: Global holidays affect attendance records platform-wide — if an employee checks in during a global holiday period, their check-in is flagged as occurring on a non-working day. Plan ahead and add major holidays before the start date.
