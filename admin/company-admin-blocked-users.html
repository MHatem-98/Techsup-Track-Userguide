Blocked Users

Manage blocked users — prevent unwanted communication with specific employees or stop receiving messages from particular contacts.

Managing Blocked Users

The Blocked Users page shows all employees or contacts you have blocked from messaging you. Block users to prevent unwanted communication, and unblock them anytime if you want to resume contact. This feature provides control over your chat experience and communication preferences.

Understanding Blocked Users

When you block a user, that person cannot send you direct messages or see your online status. You will not receive notifications from their messages, and the conversation history may be hidden depending on your preferences. Blocking is a one-way action — the blocked user may not know they're blocked.

Why Block a User?

•

Unwanted Communication

Prevent repeated or unwanted messages from a specific contact.

•

Focus & Productivity

Minimize distractions by blocking non-essential communications.

•

Professional Boundaries

Set professional boundaries with colleagues you prefer not to chat with.

•

Harassment Prevention

Protect yourself from harassment or inappropriate messages.

Blocked Users List

This page displays all users you have currently blocked from messaging you. If you have no blocked users, the page will show "No blocked users at the moment" and explain how to block a contact.

Blocking a User

To block someone from messaging you:

1

Go to Chat Section

Navigate to the Chat page and open a conversation with the person you want to block.

2

Access Contact Options

Click on the contact's name or profile to open their options menu.

3

Select Block User

Choose the Block User option from the menu to immediately block this contact.

4

Confirm the Action

Confirm when prompted. The user is now blocked and cannot message you.

Unblocking a User

If you want to resume communication with a previously blocked user:

1

Open Blocked Users

Go to the Blocked Users page to see your list of blocked contacts.

2

Find the User

Locate the person you want to unblock in the blocked users list.

3

Click Unblock

Select the Unblock action to remove this user from your blocked list.

4

Resume Communication

The user can now message you again, and you can see their messages in your chat.

Tip: Review your blocked users list regularly. If you've resolved issues with blocked contacts, consider unblocking them to restore professional relationships.
