Default Project Tasks

Manage predefined projects and their default tasks — templates that can be assigned to companies.

Managing Default Projects

The Default Project Tasks page displays a library of platform-wide template projects, each with a set of predefined tasks. When a company creates a new project, they can use one of these templates to instantly populate tasks, saving time and ensuring consistency.

The Default Projects & Tasks Table

Column What it shows
# The row number in the list
Project Name The name of the template project (e.g. "HR Onboarding", "Customer Support", "Product Development")
Tasks A list of the default tasks included in this project template, displayed as checkmarks with task descriptions
Tasks Count A blue badge showing how many tasks are defined for this project (e.g. 2, 3)
Actions A button to view, edit, or manage this project template — for example, to add or remove tasks, or change the project description

Using Project Templates

  • When a company admin creates a new project, they see an option to use a default template from this list
  • Selecting a template automatically creates the project with all its predefined tasks
  • Companies can customize the tasks after creation — templates are just a starting point

Adding a New Project Template

Click + Add New Project in the top-right to create a new default project template.

1

Enter the Project Name

Give the template a clear, descriptive name so companies know what this project is for.

2

Add Tasks

Define the tasks that should be included in this template. Each task becomes a checklist item when the project is created by a company.

3

Save the Template

Once the project name and tasks are defined, save the template and it becomes available to all companies on the platform.

Tip: Keep template projects generic enough that multiple companies can use them, but specific enough to be useful. For example, "Client Onboarding" is better than just "Project" because it gives teams a clear context.
Note: Modifying an existing default project template does not affect projects already created by companies — changes only apply to new projects created after the edit.
