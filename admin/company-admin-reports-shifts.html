Work Record Reports

View your company's workforce skills inventory — which employees have which skills, and search across your skill database.

Reports by Shifts

The Reports by Shifts page allows Company Administrators to review employee work records and attendance activity based on assigned shifts. This report helps monitor employee attendance, working status, locations, and departmental activity during a selected date range.

Filter Options

The top section contains filtering tools that allow administrators to narrow down work records and generate accurate reports.

  • Start Date – Select the beginning of the reporting period.
  • End Date – Select the end of the reporting period.
  • Search – Search by employee name, email, contact number, or employee ID.
  • Departments – Filter records for a specific department.
  • Locations – View records from a selected work location.
  • Status – Filter employees based on attendance or work status.
Quick Tip: Use the predefined date buttons such as Today, Last 7 Days, Last 30 Days, or Last 60 Days to quickly generate reports without manually selecting dates.

Generating a Shift Report

  1. Select the required Start Date and End Date.
  2. Optionally choose a Department, Location, or Status.
  3. Use the Search field if you want to locate a specific employee.
  4. Click Apply Filter.
  5. Review the generated work records in the table below.

Work Record Data Section

The Work Record Data table displays all matching records based on the selected filters. Administrators can review employee attendance and work activity information directly from this section.

  • View filtered employee work records.
  • Filter records further by department or location.
  • Adjust the number of displayed entries.

Exporting Reports

Once the desired records are displayed, administrators can export the report for external use.

CSV Export

Download the report in CSV format for spreadsheet applications.

Excel Export

Export report data to Microsoft Excel for further analysis.

Print Report

Generate a printer-friendly version of the report.

If no records are found, verify the selected date range and filter criteria. The system will display a "No work record data found" message when no matching records exist.
