Create File

Upload a new file — specify details, select recipients, and send files to specific departments or locations.

Uploading a New File

From the Files page, click + Create New File to open the file upload form. Add file details, specify recipients, and distribute files to teams.

Step 1 — File Information

1

Attachments*

Select the file(s) to upload. You can attach multiple files (PDF, images, documents, spreadsheets, etc.) — required.

2

File Name

Enter a descriptive file name (optional). If not provided, the system uses the original file name.

3

Description

Optional: Add notes about the file's purpose, contents, or context to help recipients understand its importance.

Step 2 — Recipients & Distribution

1

Recipient File*

Choose which department or location should receive this file (required).

2

Department

Select the department that owns or manages this file (optional).

3

Select All Recipients

Check this box to automatically send the file to all departments and team members.

4

Select Recipients (Manager)

Manually select specific team members or managers to receive the file.

Step 3 — Location Assignment

Choose work locations where this file should be accessible (optional). This is useful for location-specific documents or policies.

Save the File

Once all required fields are completed, click Create File to upload and distribute the file, or Cancel to discard the form.

Tip: Use clear file names and descriptions. Include relevant department/location information to ensure the right people receive files. Always verify the recipient list before uploading sensitive documents.
