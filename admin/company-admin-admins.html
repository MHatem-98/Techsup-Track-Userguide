Admins Management

Manage company administrators and their permissions

Overview

The Admins Management page provides a centralized interface for managing all system administrators. Here you can view admin statistics, search for specific admins, filter by status, and add new administrators to your organization.

Understanding the Admin Statistics

At the top of the Admins Management page, you'll find four important statistics:

1

Total Admins

Displays the complete count of all administrators in your system, including active, inactive, and pending admin accounts.

2

Active Admins

Shows the number of admins who are currently active and have full access to the system. These are the admins actively managing your company.

3

Pending Admins

Indicates admins whose accounts are still pending verification or activation. These admins may not have full access yet.

4

Inactive Admins

Displays the count of admins who have been deactivated. These admins no longer have access to the system.

Search and Filter Options

Use the search and filter section to find specific administrators:

1

Search Box

Enter an admin's name, email address, or ID number to quickly locate specific administrators. The search filters results in real-time as you type.

2

Status Filter

Filter admins by their current status: Inactive, Active, or Pending. This helps you quickly view admins in a specific state.

3

Filter Button

Click the Filter button to apply your selected criteria and display matching administrators.

4

Reset Button

Click Reset to clear all filters and search terms, returning to the complete admin list.

Admins List Section

The Admins List displays all administrators in a table format with the following columns:

•

Profile Picture

The admin's avatar or profile image for quick visual identification.

•

Full Name

The complete name of the administrator.

•

Email

The admin's email address for contact and authentication purposes.

•

Status

Shows whether the admin account is Active, Inactive, or Pending.

•

Actions

Click on action buttons to edit, deactivate, view details, or delete an admin account.

Adding a New Admin

To add a new administrator to your system:

  1. 1Click the + Add New Admin button in the top-right corner of the page.
  2. 2Fill in the admin's personal information (name, email, contact details).
  3. 3Set a secure password and enable monitoring/logging options.
  4. 4Click Save to create the admin account.
Tip: For detailed instructions on adding new admins, refer to the "Add New Admin" guide page.

Best Practices

  • Limit Admin Access: Only assign admin roles to trusted personnel. The fewer admins you have, the easier it is to manage access.
  • Monitor Admin Activities: Regularly review Activity Logs to track what each admin is doing in the system.
  • Use Strong Passwords: Ensure all admin accounts have secure, complex passwords. Change passwords regularly.
  • Deactivate Unused Admins: If an admin no longer needs system access, deactivate their account rather than deleting it.
  • Regular Audits: Periodically review the list of active admins and verify that access is appropriate.
Important: Admin accounts have complete system access. Be cautious when creating or modifying admin accounts. Always follow your organization's security policies.
