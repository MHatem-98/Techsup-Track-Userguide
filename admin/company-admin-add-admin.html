Add New Admin

Create new administrator accounts with custom permissions and security settings

Accessing the Add New Admin Form

To create a new administrator account:

  1. 1Navigate to Admins Management from the sidebar.
  2. 2Click the + Add New Admin button in the top-right corner.
  3. 3The Add New Admin form will open with all available fields.

Personal Information Section

This section collects basic details about the admin:

1

Profile Photo

Upload a profile picture for the admin (JPG, PNG, or GIF format). Maximum file size: 2MB. This image will be displayed in the admin list and throughout the system.

2

First Name * (Required)

Enter the admin's first name. Example: "Ahmed".

3

Last Name * (Required)

Enter the admin's last name. Example: "Hassan".

4

Email * (Required)

Enter a valid email address. This email will be used for login and system notifications. Example: "ahmed.hassan@company.com".

5

Contact Number

Enter the admin's phone number for contact purposes. Example: "+966501234567".

6

Address

Enter the admin's physical address or office location for administrative records.

Security Information Section

Configure the admin's authentication credentials:

1

Password * (Required)

Create a strong, secure password for the admin account. Requirements:

  • At least 8 characters long
  • Include uppercase letters (A-Z)
  • Include lowercase letters (a-z)
  • Include numbers (0-9)
  • Include special characters (!@#$%^&*)
2

Confirm Password * (Required)

Re-enter the password to confirm it matches. This prevents typos and ensures you've set the intended password.

Important: Create a strong password. Avoid using simple passwords or personal information. Consider using a password manager to generate secure passwords.

Settings Section

Configure monitoring and logging options for this admin account:

☑

Enable Screenshot Monitoring

When checked, the system will automatically capture periodic screenshots of the admin's desktop. This helps with compliance and security auditing. Recommended: Enable this for all admin accounts.

☑

Enable Activity Logs

When checked, all actions performed by this admin (login, data changes, deletions, etc.) will be recorded in the Activity Logs. Recommended: Enable this for all admin accounts.

Saving the Admin Account

Once you've completed all required fields:

  1. ✓Review all information for accuracy.
  2. ✓Click Save to create the admin account.
  3. ✓Click Cancel to discard changes and return to the Admins list.
Tip: After creating an admin account, the new admin will receive a welcome email with their login credentials. They should change their password on first login for security.

Security Best Practices

  • Use Strong Passwords: Never use the same password for multiple admin accounts. Each admin should have a unique password.
  • Enable All Monitoring: Always enable both screenshot monitoring and activity logs for comprehensive security tracking.
  • Verify Email Address: Ensure the email address is correct and actively monitored so the admin receives important system notifications.
  • Regular Reviews: Periodically review the list of active admins and verify that access is still needed.
  • Document Admin Creation: Keep a record of when admin accounts were created and by whom for audit purposes.
Important: Admin accounts have complete system access. Only create admin accounts for trusted personnel. Regularly review and monitor all admin activities to maintain system security.
