COMPANY ADMIN GUIDE

All Projects

View and manage all company projects — active, inactive, public, private — in a single dashboard with filtering and search capabilities.

Managing Projects

The All Projects page displays every project under your company — whether it's active, archived, public, or private. From here, you can create new projects, search for specific ones, filter by various criteria, and take bulk actions.

Project Summary Cards

Total Projects

Complete count of all projects in the company.

Public Projects

Projects visible to all team members.

Private Projects

Projects restricted to specific team members.

Active Projects

Projects currently in progress.

Searching and Filtering

1

Search by Name

Type in the search box to find projects by name, description, or keywords.

2

Filter by Category

Select a category to narrow results to projects in specific areas of work.

3

Filter by Employee

Show only projects assigned to or managed by a specific team member.

4

Filter by Type

Select Public, Private, or Active/Inactive to see projects matching specific criteria.

Projects Table Columns

Column What it shows
Project Name The name and type (Public/Private badge) of the project
Type Public or Private designation
Status Active or Inactive
Due Date Projected completion date
Assigned Users Team members working on the project
Actions Menu to view, edit, or delete the project

Quick Actions

  • + Create Project — launch the new project form
  • Trashed Projects — view deleted projects available for recovery
Tip: Use projects to organize work by team, client, or initiative. Keep project descriptions clear so team members understand the goal and scope.
