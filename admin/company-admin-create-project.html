Create Project

Start a new project — define scope, assign team members, set dates, and configure visibility for your team to collaborate.

Creating a New Project

From the All Projects page, click + Create Project to open the project creation form. Fill in the basic information and project details to set up your new project.

Step 1 — Basic Information

1

Project Name*

Enter a clear, descriptive name for the project (required). Examples: "Q4 Marketing Campaign", "Client Portal Redesign", "Infrastructure Upgrade".

2

Description

Optional: Provide a detailed description of what the project entails, goals, and success criteria.

3

Project Type*

Choose the type: Public (visible to all team members) or Private (restricted to assigned members) — required.

Step 2 — Project Details

1

Start Date*

Set the project start date in mm/dd/yyyy format (required).

2

End Date*

Set the projected end date (required). This is used to calculate project duration and deadlines.

3

Department

Select which department will own this project (optional).

4

Assigned Users

Select team members to assign to this project (optional at creation — can be added later).

Step 3 — Attachments

Optionally upload relevant files (project briefs, requirements documents, images, PDFs, etc.) by dragging and dropping or clicking Choose Files.

Save the Project

Once all required fields are filled, click Save to create the project, or Cancel to discard the form.

Tip: Create a clear, specific project name and description so team members understand the goal immediately. Use meaningful dates to keep everyone aligned on deadlines.
