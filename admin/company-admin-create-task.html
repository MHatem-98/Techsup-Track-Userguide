COMPANY ADMIN GUIDE

Create Task

Create a new task — assign it to a project, set a due date, and delegate it to a team member.

Creating a New Task

From the Tasks page, click + Create Task to open the task creation form. Fill in the task details to create a new task and automatically assign it to an employee.

Step 1 — Basic Task Information

1

Task Name*

Give the task a clear, concise name that describes what needs to be done. Examples: "Review client proposal", "Fix login bug", "Write product documentation" (required).

2

Description

Optional: Provide detailed instructions, acceptance criteria, or additional context to help the assignee understand exactly what's needed.

3

Priority*

Set task priority: Low, Medium, or High (required).

Step 2 — Project & Assignment

1

Select Project*

Choose which project this task belongs to from the dropdown (required).

2

Assign To*

Select the team member responsible for completing this task (required).

Step 3 — Due Date & Status

1

Start Date

Optional: When should work begin on this task (optional).

2

Due Date*

Enter the deadline (required). This should be realistic and agreed upon.

3

Initial Status*

Set the initial status: Not Started, In Progress, or Completed (required).

Step 4 — Attachments (Optional)

Upload any reference files, images, or documents that help clarify the task requirements by dragging and dropping or clicking Choose Files.

Save the Task

Once all required fields are completed, click Save to create the task, or Cancel to discard the form.

Tip: Clear task names and good descriptions reduce back-and-forth questions. Set realistic due dates and always notify the assignee about their new tasks right away.
