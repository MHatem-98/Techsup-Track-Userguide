SUPER ADMIN GUIDE

Admins Reports

Track every Super Admin account on the platform — their status, verification, and how much they've created — from a single report.

Understanding Admins Reports

The Admins Reports page (found under Home → Admins Reports) gives you a platform-wide view of Super Admin accounts: who has access, whether they're verified, and how many companies or employees each one has created.

Filtering by Date

Just like the Home dashboard, this report can be scoped to a time range.

1

Choose a Quick Filter

Select Today, Last Week, This Month, or This Quarter to instantly update the report.

2

Or Use a Custom Range

Set a Start Date and End Date, then click Search. Click Reset to clear the filter.

Summary Cards

Total Admins

The full count of Super Admin accounts on the platform.

Active Admins

How many admin accounts are currently active, shown as both a count and a percentage of the total.

Verified Admins

Admins who have completed email/account verification, again shown as a count and percentage.

Super Admins

Total Super Admin accounts, with a note on how many are System Admins.

Total Created Employees

Number of employees created directly by Super Admins during the selected period.

Total Created Companies

Number of companies created directly by Super Admins during the selected period.

Status Breakdown

A quick-glance strip shows how the admin accounts split across four states: Active, Pending, Inactive, and Verified.

The Super Admins Report Table

The table at the bottom lists every Super Admin account individually.

Column What it shows
# Row order in the list
Name / Email The admin's display name, internal ID, and email address (a checkmark next to the email means it's verified)
Status Active or inactive account status badge
Created At Date and time the admin account was created
Total Companies How many companies this admin has created or manages
Total Employees How many employees this admin has created
Actions View or manage the admin's account (icons on the right of each row)
Tip: If an admin shows 0 for Total Companies and Total Employees, it means they haven't directly created any records themselves — they may still manage records created by others.
