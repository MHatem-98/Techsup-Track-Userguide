Create Shifts

Define new shift patterns — set shift names, hours, durations, and assign them to employees or departments.

Creating New Shifts

From the Manage Shifts page, click + Create Shift to define a new shift pattern. Set shift details, configure working hours, and assign the shift to employees or departments for scheduling.

Shift Basic Information

1

Shift Name*

Enter a descriptive shift name (required). Examples: "Morning Shift", "Evening Shift", "Night Shift", "Weekend Shift", "Part-Time Shift".

2

Shift Type

Select the shift type: Regular, Night, Flexible, On-Call, or Custom. This helps categorize shifts for reporting and scheduling purposes.

Shift Working Hours

1

Start Time*

Set the shift start time (required). Example: 9:00 AM for a morning shift.

2

End Time*

Set the shift end time (required). Example: 5:00 PM for a morning shift (8 hours).

3

Shift Duration

The system automatically calculates total shift duration (hours) based on start and end times.

4

Break Duration (Optional)

Specify how much break time is included in this shift (if any). Example: 1 hour lunch break.

Shift Assignment

1

Assign to Department

Optionally assign this shift to a specific department. All employees in that department can be assigned to this shift.

2

Assign to Location

Optionally assign this shift to a specific work location. Employees at that location can use this shift.

3

Maximum Employees

Set a limit on how many employees can be assigned to this shift simultaneously (optional).

Additional Settings

•

Status

Mark the shift as Active or Inactive. Inactive shifts cannot be assigned to employees.

•

Description (Optional)

Add notes about the shift (e.g., "Customer-facing role", "Requires certification").

Saving the Shift

Once you've completed all required fields:

  1. ✓Click Save Shift to create the shift pattern and add it to your scheduling system.
  2. ✓Click Cancel to discard changes and return to Manage Shifts.
Tip: Create shifts that match your business operations. Use clear, descriptive names so employees immediately understand which shift they're assigned to. Consider creating flexibility in shift times to accommodate different work arrangements.
